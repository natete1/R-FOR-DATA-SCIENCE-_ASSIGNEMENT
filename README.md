

# R Programming Assignments

This repository contains my R programming assignments and practical exercises completed as part of the **Master of Science in Big Data Analytics** program at the Adventist University of Central Africa (AUCA).

The projects cover data importing, data management, visualization, statistical analysis, R functions, apply functions, and regression analysis.

## Activities Covered

### 1. Class Activities

- Performing tasks covered during class activities.
- Practicing R commands and programming concepts.
- Solving statistical and data analysis exercises.

### 2. Data Import in R

- Importing datasets into R.
- Importing CSV, Excel, and SPSS files.
- Accessing data through APIs and websites.
- Connecting R to MySQL databases.
- Working with built-in R datasets.

### 3. Geoms and Data Visualization in R

- Creating visualizations using `ggplot2`.
- Creating scatter plots, line graphs, boxplots, histograms, and bar charts.
- Exploring different `geom` functions.
- Interpreting graphs and presenting conclusions.

### 4. Data Management and Cleaning

- Inspecting and understanding datasets.
- Identifying and handling missing values.
- Renaming variables and changing data types.
- Detecting potential outliers.
- Preparing datasets for statistical analysis.

### 5. R Functions

- Using built-in functions.
- Creating and applying user-defined functions.
- Calculating descriptive statistics.
- Working with mean, median, mode, standard deviation, minimum, and maximum.

### 6. Regression Analysis

- Simple and multiple linear regression.
- Polynomial regression.
- Regression assumptions and diagnostic analysis.
- Interaction effects.
- Multicollinearity analysis using VIF.
- Model comparison and interpretation.
